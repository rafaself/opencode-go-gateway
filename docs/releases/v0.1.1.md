# OpenCode Gateway v0.1.1

## Fixes

- `setup codex` now accepts and preserves valid multiline TOML collections,
  including the `tool_suggest.discoverables` array written by current Codex
  configurations.
- Unclosed collections still fail safely before any Codex file is written.

The release keeps the v0.1.0 protocol, provider, credential, and installation
behavior unchanged. See the [README](../../README.md) and
[release guide](../release.md) for setup and verification details.
