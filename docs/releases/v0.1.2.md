# OpenCode Gateway v0.1.2

## Fixes

- The capture server now rechecks the final fixture path while holding its
  reservation, preventing concurrent capture servers from reusing a sequence
  after a fixture is written.

This release includes the v0.1.1 fix for multiline TOML collections in Codex
configuration. See the [README](../../README.md) and [release guide](../release.md)
for setup and verification details.
